To run the PacMan game, the entire PacMan folder should be opened
in your preferred IDE (Visual Studio Code was used in the creation of this project),
Then run pacman/demo/src/main/java/com/example/App.java.

Specifications for Java Version:
- Java: 21
- JavaFX: 21
- Maven Compiler Plugin: 3.8.0

- JavaFX Maven Plugin: 0.0.6
